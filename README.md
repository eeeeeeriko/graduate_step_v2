# README
## 1. サービス概要
- このサービスはどんなサービスか（3行以内）
  ワインを勉強し始めた初心者向けに、日々の食事やスクールで飲んだワインの特徴を手軽に記録しながら、産地や品種の知識も自然と深められるワイン学習・管理アプリ。
- 誰の、どんな課題を、どう解決するか
  ワインを好きになりたい・勉強したい30代のビジネスパーソンが、既存アプリの煩雑さや入力の手間、専門性の高さによって「好みの軸や知識が定着しない」という課題を解決する。
  直感的なUIで記録を蓄積しつつ、学びのコンテンツを通じて自分の好みを言語化し、外食やビジネスの場で自信を持ってワインを選べるようになる体験を提供。

---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情
- 26年4月～10月
- ワイン教室に通い、授業やプライベートで多くのワインをテイスティングする中で、「自分が本当に好きなワインの傾向（ぶどう品種、産地、味わいの特徴など）」を体系的に整理・把握したいと思った。しかし、飲んだワインをその都度ただ写真や断片的なメモに残すだけでは、後から「自分がこれまでどんなワインを飲み、何に美味しいと感じたのか」をスムーズに振り返ることができなかった。

---

### 2-2. なぜそれが「気になった」のか
- 自分の性格：長文のテキスト入力を伴う記録は途中で面倒になって続けられなくなる
- 過去の経験：お酒を楽しく飲み続けてしまうため、どんな銘柄を飲んだのか、その時どう感じたのかの記憶が曖昧になってしまう
- 大切にしている価値観：「記録して終わり」ではなく、自分の飲酒体験（データ）を蓄積・振り返ることで、「自分の好みの軸」や「自分の感性」を深く知りたいという欲求がある。また、それをただの自己満足で終わらせず、外食時や取引先の飲み会といったリアルなシーンでスマートに引き出せるようにしたい

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと

その体験の中で、最初に感じた「困りごと」は何ですか？
既存のワイン記録アプリや汎用的なお酒記録アプリがあるが、多機能すぎて「5段階評価」くらいしか使わない、「詳細なコメントを長文で入力しないと保存できない」仕様になっている。

ワイン以外のお酒（ビールや日本酒など）も混ざってしまい、ワイン特有の軸で管理しにくい。また、広告や不要な機能が多くて煩雑
---

### 3-2. 本当に解決したい課題は何か

「なぜそれが困るのか？」を**最低3回**繰り返してください。

- なぜ？
既存のグローバルアプリ（VIVINO等）は多機能で便利である一方、機能が多すぎて使いこなせず、結局大まかな5段階評価しかつけられなくなり、本来ワインの持ち味であるタンニン、酸味、香りなどの具体的な情報を自分のデータとして残せないから。
- なぜ？
タンニンや酸、香りの詳細な情報を自分で残そうとすると長文の入力を強いられ、お酒の席や日々の忙しさの中で記録するハードルが高すぎて続かないから。
- なぜ？
記録が続かないことで、せっかくワインを飲んで勉強しているのに「自分は何が美味しくて、どういう特徴のワインが好きなのか」の軸が自分の中に定着せず、お店でワインを選ぶときにいつまでも自信が持てないから。

→ 本当に解決したい課題：記録が続かないことで、せっかくワインを飲んで勉強しているのに「自分は何が美味しくて、どういう特徴のワインが好きなのか」の軸が自分の中に定着せず、お店のワイン選びでいつまでも自信が持てないこと。

※「アプリでできそうなこと」ではなく
※「人の行動・感情の問題」になっているか確認してください。

## 4. 想定ユーザーについて

### 4-1. 想定しているユーザー

年齢設定：
  - 年齢：30代前半のビジネスパーソン
  - 理由：20代は上司や取引先に連れられてお店を知るようになるが30代になると自分でお店を選ぶ、ワインメニューを選ぶ立場になってくる世代。仕事や周囲の影響でワインに興味を持ち始め、スクールに通ったりプライベートでワインショップに行き始めるから。

生活・状況設定：
  - 生活・状況：週末や仕事帰りの会食（上司や取引先との飲み会、デートなど）でワインを飲む機会がある。ワインリストを渡されたり、「何かおすすめある？」と聞かれたりするシーン
  - 理由：ワインリストを見ても専門用語ばかりのため「どれが自分の好きな味だったっけ…？」と内心焦ってしまう。そんな緊迫した場面でも、過去に自分で記録したアプリをサッと見返して、「自分はこういう酸味が好きだから、これなら大丈夫そう」と自信を持って選ぶためにこのアプリが必要

環境設定：
  - 環境：アプリの入力時間が隙間時間しかない。
  - 理由：家に帰ってからPCを開いたり、長文の日記を書く余裕はないため、その場で登録しやすいような仕組みが必要。そこで「酸味」や「渋み」などのワインの特徴を入力しやすいようにする。

## 7. このアプリで実現すること

### MVPで作る機能
・ログイン機能画面
・ユーザー登録画面
・ワインの新規登録画面・編集画面・削除画面
　- 文字入力が必要な項目
 　　・ワイン名　
　- タップで選ぶ項目
 　　・味わいの特徴　
 　　　　「酸味（強/中/弱）」「タンニン（強/中/弱）」「甘口/辛口」
 　　・その時の満足度（「好み/普通/好みじゃない」）
・記録一覧画面
　※自分が登録したワインや味わいの特徴を一覧で見る

　■飲酒中にその場で必ず残す必須情報:
　・ワイン名
　・味わいの特徴
　　　　※飲んだ瞬間じゃないとわからないため
　・その時の満足度（「また飲みたい / 普通」の2〜3択など）
　■任意・後から追記する情報:
　・自由記述のコメント（具体的な香りのノート）※本リリースとする

### 本リリースで作る機能
・ラベル画像アップロード
　※AI解読できれば、国・品種・産地などが分かるのでより特徴がわかるが実現が難しいためいったんラベル画像のアップロードのみ
・香り選択タップ
　※例えば赤ワインのカベルネ・ソーヴィニオンならピーマンの香りがするので、ピーマンが選べるようにする。
・自由記述のコメント（具体的な香りのノート）
　※想定ユーザ・利用例を考慮したとき、実際にユーザが手入力すると思えないため本リリースとする。
・初心者向けのワインサポート・学習コンテンツ（国別のワインや代表的なぶどう品種の特徴解説など）

※ラベル画像について:
ラベル画像のアップロードは本リリース予定とするため、MVPでは各ワインの記録を見分ける手段として、「ワイン名」のテキスト入力と、登録日時をリストの目印として使用する。

####　具体的な利用例（振り返りの流れ

- 数件記録した後、どの画面で何を見返すか:
ワインを3〜5本ほど記録した段階で、マイページの「記録一覧画面」を開く。

- 何を手がかりに、好きだった特徴を把握するか:
記録一覧画面で、自分が「また飲きたい（好み）」と評価した複数のワインの記録を見比べる。「共通して『酸味が強い』の項目にチェックが入っているな」という共通する味わいの傾向を手がかりに、「自分はこういう特徴のワインが好きなんだな」と好みの軸を把握する。

- 次のお店で、自分の好みをどのように説明できるようになるか:
外食の際、スマホの記録一覧をサッと開き、「前回ここで『酸味がすっきりしたタイプ』が美味しいと感じたので、これに近いおすすめはありますか？」と、自分の好みの傾向を自分の言葉で店員さんにスマートに説明できるようになる。


## 8. このアプリの懸念点とその対策
※最低1つは必ず書いてください。

このアプリが**うまくいかない可能性**と、
それに対して**どう向き合おうとしているか**を書いてください。

### 懸念点①

- 何が問題になりそうか：記録のハードルを下げても、毎回の飲酒シーンでアプリを開いて入力するアクション自体が面倒になって使われなくなる可能性
- なぜそう思うか：飲みの席ではテンションが上がっており、後からまとめて入力しようとして忘れてしまうケースが多いため。
- そのために考えている対策：隙間時間（移動中や翌日）に終わらせられるような入力しやすいUX設計にする。
